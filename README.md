
Pre-requisites:

- feed videos in the `input` folder from which the program will process the
- add in the folder `songs_background` the songs you wanna use as background music for your videos


Preparation based on OS:

WINDOWS:

- Place in the folder the binary from this url: https://github.com/qxZap/video-uniquizer/raw/refs/heads/main/ffmpeg.exe?download=
- install python3
- run `python3 -m pip install -r requirements.txt`


MAC:

- Install homebrew https://brew.sh/
- Install ffmpeg with command `brew install ffmpeg`
- install python3
- run `python3 -m pip install -r requirements.txt`


How to run??

Type in the console in this folder: `python3 convert.py`
